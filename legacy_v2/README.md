# Version 2 (superseded)

`benchmark_colab_v2.py` fixed the version 1 faults. It was superseded by version 3, which
removed heart-failure follow-up time (post-baseline leakage), treated Pima zeros as missing,
extended the bandwidth grid, gave the VQC an all-qubit readout and added the finite-shot,
all-predictor, implementation-sensitivity and qubit-scaling analyses. Its results are kept in
`../results/superseded/v2_benchmark_results.json` and are not reported in the paper.
